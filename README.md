# World Landmarks Explorer

A responsive static website showcasing two iconic world landmarks: Chichén Itzá in Mexico and the Taj Mahal in India.

## Features

- Landmark images and historical summaries
- Responsive layout for different screen sizes
- Navigation menu
- Learn More links for additional information
- Clean HTML5 and CSS3 design

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Media Queries
